# eNSP MCP 管理工具

本项目为 eNSP 网络模拟器提供网页管理界面和 MCP 接口，支持设备扫描、Telnet 命令、拓扑分析、流量监控及 AI 辅助操作。当前项目代码位于 [mcpenspv2](mcpenspv2/)，详细的安装与使用说明见 [2.0 使用文档](mcpenspv2/README.md)。

## 快速启动

在 Windows PowerShell 中进入 `mcpenspv2` 目录，安装依赖并启动服务：

```powershell
cd mcpenspv2
python -m pip install -r requirements.txt
python app.py
```

浏览器访问 `http://127.0.0.1:5000`；MCP SSE 地址为 `http://127.0.0.1:5001/sse`。拓扑流量监控还需要 Wireshark、Npcap 和运行中的 eNSP 设备。

- 增加数据包内容自动分析，展示常见协议字段及可识别的报文截断、长度异常。
- 增加报文溯源和慢放，按捕获方向在拓扑图中播放，并根据报文指纹、时间与相邻设备推测后续路径；推测结果可能受报文丢失或重传影响。

## 使用提示

- AI 对话内容、工具结果和设备命令输出会发送给所配置的 AI 服务；请按使用场景选择服务并保护 API 密钥。
- 拓扑流量数值基于当前环境中观察到的 eNSP UDP 封装进行估算，并非设备接口的精确统计；具体支持范围和限制见 [2.0 使用文档](mcpenspv2/README.md)。
